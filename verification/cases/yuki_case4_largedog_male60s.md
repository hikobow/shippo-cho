# アドバイス
大型犬との暮らし、いいですね。お話を伺うかぎり、犬を迎えることは十分に前向きに考えられると思います。体力に合うかどうかは、犬種を選ぶことと、これからの暮らし方で変わってきます。

まず体力のことです。大型犬は引く力が強く、散歩中の転倒に気をつけたい面があります。年齢を重ねてからは、起き上がりや歩行を手伝う介助も力仕事になります。ですので、いまのうちに散歩の習慣を一緒に作って、落ち着いた成犬に育てておくと、後々ぐっと楽になります。寿命は大型犬で12歳前後、長生きしても14〜15歳くらいが目安です。いま迎えると、犬が高齢になる頃にはご自身も70代後半から80歳前後になります。息子さんが引き継いでくださるとのことなので、早いうちから息子さんにも散歩やお手入れに関わってもらい、犬に慣れてもらっておくと、いざという時に引き継ぎやすくなります。日々のお世話は、同居の大人であるあなたを中心に組み立てておくと無理がありません。

体力の面で比べやすい犬種として、まずゴールデンレトリバーがあります。穏やかで家族に寄り添ってくれ、初めての人にも飼いやすいとされています。お世話で気をつけたいのは抜け毛です。換毛期は毎日のブラッシングが必要で、体重が増えすぎないよう、関節にも気を配ると安心です。もう一つはラブラドールレトリバーです。人懐こく、比較的飼いやすい犬種です。散歩は1日2回、各30〜60分ほどが目安で、さみしがりな面もあるので、留守の時間は短めにしてあげると落ち着きます。どちらも股関節の形成に関わる病気が出ることがあるので、迎える前に親犬の情報や検査の様子を確かめておくと安心です。

予算については、具体的な金額はここではお伝えできません。大型犬は食事の量も多く、医療や通院の移動などでも費用がかかります。迎える前に、かかりつけ予定の動物病院やお店で、食事や予防、医療の目安を聞いて、ご家庭で長く続けられる形を確かめておくとよいと思います。

先住の猫ちゃんは11歳なので、新しい子が来る時は猫ちゃんを優先してあげてください。最初は部屋を分けて、においや気配から少しずつ慣らしていく方法がおすすめです。迎えて最初の2〜3か月は、家族の誰かが家にいられるとのことなので、仔犬の時期も乗り切りやすいと思います。年に1〜2回の泊まりがけのお出かけの時は、連れて行くか、預け先を決めておくとよいでしょう。

次の一歩としては、ゴールデンやラブラドールの成犬に会わせてもらって、体の大きさや力を実際に感じてみるのがお勧めです。あわせて、いまの猫ちゃんのかかりつけの獣医さんに、新しい犬を迎える計画を話しておくと、心強い味方になってくれます。
