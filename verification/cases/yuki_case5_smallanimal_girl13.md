# アドバイス
ペットを迎えたいというお気持ち、そしてお誕生日の約束のあとに、ご自身でちゃんと調べようとされているところが素敵です。小動物の中なら、モルモットがいちばん前向きに考えやすいと思います。ハムスターも、お世話の中心を親御さんにする形なら迎えられます。

ひとつ、先にお伝えしておきたいことがあります。13歳の方が「全部自分でお世話する」と決意されても、毎日の世話を何年も続けるのは、実際にはとても大変です。結局は親御さんが飼い主の形になることが多いので、最初から「飼い主は親御さん、毎日の世話はご自身が中心」という形にしておくと続けやすくなります。親御さんがこの話をどう考えているかは、まだ伺えていません。そこで、「いつ、何をするか」を書き出して見せながら、一度ゆっくり話してみてください。

モルモットは、寿命が7〜8年ほどです。いま13歳なら、高校や進学、場合によっては一人暮らしの時期まで一緒に過ごすことになります。そのころの暮らし方を、親御さんと少し話しておくと安心です。世話は毎日あります。フンの掃除、牧草と水の交換、ビタミンCの補給は欠かせません。ケージは17〜24℃くらいの部屋に置くと元気に過ごせます。鳴き声は小動物の中では大きめで、早朝や夕方に目立つので、置く場所を考えておくとよいです。触れ合いはいくらかできますが、基本は見て楽しむ動物です。

ハムスターは寿命が2〜3年と短く、夜によく動き、回し車の音がします。小さな体はとても繊細で、子どもだけで飼うのは難しい動物です。世話を担う親御さんがいてこそ、お迎えしやすい動物です。ゴールデンやキンクマという種類は、おだやかで扱いやすいと言われます。

マンションなので、小動物を飼えるかどうかは、管理会社や大家さんに確かめておくと安心です。ご家族に動物アレルギーがあるかどうかは、いまは分かっていないようです。小動物は、毛や牧草、かまれたときの唾液で、アレルギーの反応が出ることがあります。迎える前にご家族の様子を気にかけて、心配なら病院で相談してみる方法もあります。

小動物は、診てもらえる動物病院が少なめです。迎える前に、近くに診られる病院があるか、電話で聞いておくと万が一のときに慌てません。泊まりがけの外出は年に1〜2回とのことなので、そのときは、お世話を頼める人を決めておくと安心です。モルモットは2日以上空けるのは避けたいので、親御さんにお願いする形が現実的です。

食事や医療、床材などの費用は、ずっとかかり続けます。何にどのくらいかかるかは、お店や動物病院で目安を聞いてみてください。

次のステップとして、まずペットショップでモルモットとハムスターを見せてもらい、お世話の様子を店員さんに聞いてみるのがお勧めです。できれば親御さんと一緒に行けるとよいですね。
