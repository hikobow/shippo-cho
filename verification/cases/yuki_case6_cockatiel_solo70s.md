# アドバイス
オカメインコ、テレビで見て「いいな」と思われたのですね。一人暮らしで日中ほとんどお家にいらっしゃるご様子は、オカメインコにとても合っています。長い時間ひとりにされるのが苦手な鳥なので、そばに人がいる暮らしは何よりの環境です。マンションも1匹までなら飼えるとのことですから、迎える準備を進めていく方向で考えてみましょう。

ご年齢についてです。オカメインコは小鳥の中でも長生きで、十数年、長ければ20年近く一緒に暮らすことがあります。ですので、年齢だけで迎えるかどうかを決める必要はありませんが、お体の調子が悪いときや入院のときに誰が世話をするかは、先に決めておくと安心です。近くに娘さんがいらっしゃるとのことなので、迎える前に鳥のことを伝えて、いざというときに引き取ってもらえるか、数日だけ預かってもらえるかを話しておくと、ぐっと気が楽になります。餌や水の替え方、1日の世話の流れを紙に書いて残しておく方法もあります。

おしゃべりについては、話す子もいますが、どの子が話すようになるかは個体差が大きく、迎えてからでないと分からない部分があります。話さなくても、呼びかけに鳴いて返してくれたり、そばで過ごしたりする楽しさは十分にあります。お店で、話すことが多い種類の特徴や、その子の様子を聞いてみるとよいでしょう。

鳴き声は、朝夕に大きな声で呼び鳴きをすることがあり、とくにオスはよく鳴く子が多いとされています。お隣や上下階の方もペットを飼っておられるとのことで、事情を分かってもらいやすい環境です。それでも、鳴きやすい時間帯に声をかけて落ち着かせる、夜はカバーをかけてしっかり眠れるようにする、といった工夫をしておくと、より穏やかに暮らせます。

そのほか、オカメインコは粉のような脂粉が多く、掃除の手間がかかります。お掃除は毎日少しずつ、という習慣にしておくと続けやすいです。部屋の温度は、成鳥なら20〜25℃ほどを目安にしてください。また、夜中に急に驚いて暴れることがあり、羽や骨を傷めることもあるので、ケージの中に引っかかるものを置かないようにするなど、お店で対策を教えてもらうと安心です。

鳥を診てくれる動物病院は少ないので、迎える前に、近くに診てもらえる病院があるか、電話で確認しておくことをお勧めします。

次の一歩としては、鳥の専門店やお店でオカメインコに実際に会って、声の大きさや人への慣れ方を見せてもらうこと、娘さんに飼う話と万一のときのお願いを伝えること、そして近くの鳥を診る病院を探しておくことです。この3つを済ませておくと、迎えたその日から楽しい暮らしが始められます。
