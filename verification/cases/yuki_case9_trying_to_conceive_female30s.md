# アドバイス
犬、とてもいいと思います。ご家族が犬を飼っていた経験もあり、在宅勤務でほとんど誰かが家にいる暮らしは、犬にとって心強い環境です。ただ、妊活中ということなので、迎える時期は少し考えておくとぐっと楽になります。

妊活そのものへの影響は、私のほうでは分かりません。かかりつけの産婦人科で「犬を迎えたい」と伝えて、直接聞いておくと安心です。猫は、妊娠中にトキソプラズマという感染症の心配があるため、妊娠の可能性が高い時期の新しい飼育は基本的にお勧めしていません。犬と猫のどちらにするか迷っているなら、いまは犬を軸に考えるほうが進めやすいと思います。

育児との両立は、十分に目指せます。ただ、仔犬を迎えて最初の2〜3か月は、夜泣きやトイレの失敗などで睡眠が削られやすい時期です。この時期が、妊娠初期や新生児のお世話と重なると体がきついので、重ならないようにしたいところです。妊娠の時期が近いと考えていらっしゃるので、お子さんが生まれて少し大きくなってから迎えると、お互い落ち着いて暮らし始められます。妊娠前に迎える場合は、仔犬の時期をしっかり乗り越えてからの妊娠を目安にしてください。

大きさは、マンションの決まりで大型犬が不可なので、小型か中型になります。子どものいる家庭には中型のほうが向きやすい傾向もあります。例えば、キャバリア・キングチャールズ・スパニエルは、穏やかで人懐こく、家族のそばで過ごすのが好きな子です。心臓の病気が多い犬種なので、定期的な健診を続けると安心です。イングリッシュコッカースパニエルは、陽気で愛情深く、子どものいる家庭で飼いやすい犬種です。毎日の運動と、耳の手入れ、トリマーでのお手入れが欠かせません。ミニチュアシュナウザーは、小型で陽気な子が多く、抜け毛も少なめです。吠えやすい傾向があるので、早めのしつけ教室を考えておくと楽になります。いずれも個体差が大きいので、お店で親犬の大きさや性格を見せてもらってください。

お世話は、毎日の散歩をご自身が中心になって行い、つわりや体調の悪い日、雨の日はパートナーに代わってもらえるよう、事前に決めておくと続けやすいです。お子さんが生まれてからも、犬の世話はご夫婦で完結する形にしておくと安定します。お子さんの手伝いは、できるようになったら加わってもらう形で十分です。年に1〜2回の泊まりがけの外出は、犬を連れて行くか、預け先を先に探しておくと慌てません。

引っ越し先はまだ決まっていないとのことです。犬は人についていくので、犬を飼える住まいが見つかれば問題ありません。住み替えるときは、犬の大きさや頭数の決まりを、先に確かめておくと安心です。

次の一歩として、産婦人科で犬の飼育について聞いておくこと、いまのマンションの規約を管理会社に確認しておくこと、そして機会があれば、ペットショップやブリーダーで、気になる犬種の子に会ってみることをお勧めします。
