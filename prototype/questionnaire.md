# しっぽ帳 試作品: 相談票と回答の仕組み

版: v0.1（2026-10-14）。試作版 v0.3 に対応。
位置づけ: アイさん・ジミーさんに、試作品の質問の項目と仕組みを見てもらうための説明書。ページのもとのファイルは同じフォルダの `shippo-demo-template.html`（`__KB07__` と `__KB00__` の場所に、data/07_principles.md と data/00_cross_comparison.md の全文を入れて公開している）。
試作品はClaudeのページとして公開しており、ユキさんだけが開ける。AIの回答は、開いた人のClaudeで作られる。

## 流れ
1. 相談者が相談票に答える（下の11項目）。開いた時は例が入っていて、「入力を消す」で空にできる。
2. AIが相談票を読み、アドバイスに欠かせない情報が足りなければ、追加の質問を最大3つ出す（足りていれば出さない）。
3. 相談者が追加の質問に答える（空欄でもよい）。
4. AIが、相談者への語りかけの形でアドバイスを書く（800〜1400字）。考えのポイントは表示しない。
5. アドバイスの下に「お店を探す（デモ）」（ペットショップへの接続はダミー）、「アドバイスをコピー」「この相談を記録に残す（検証用）」「相談票を書き直す」「最初からやり直す」。
- 直前のアドバイスは、その端末のブラウザにだけ残る。「記録に残す」を押した時だけ、相談票・追加の質問と答え・アドバイスが保存され、クロが読める（読めるのはページの持ち主とクロだけ）。

## 相談票の項目
| 項目 | 形式 | 選択肢 |
|---|---|---|
| 迎えたい動物 | 1つ選ぶ＋自由記入 | 犬／猫／小鳥／ハムスター／モルモット／まだ決めていない。種類・犬種・猫種（自由記入） |
| その動物への思い | 1つ選ぶ | どうしてもこの動物がいい／できればこの動物がいい／なんとなく考えている（07 P13の「思いの強さ」） |
| あなたの年代 | 1つ選ぶ | 20代以下／30代／40代／50代／60代／70代以上 |
| 一緒に暮らす人 | 複数選ぶ＋自由記入 | 一人暮らし／配偶者・パートナー／子ども／親／その他。子どもの年齢など（自由記入） |
| 住まい | 1つ選ぶ＋自由記入 | 戸建て（持ち家）／戸建て（賃貸）／マンション（持ち家）／マンション・アパート（賃貸）。飼える動物の決まり（自由記入） |
| 平日、家に誰もいない時間 | 1つ選ぶ | ほとんど誰かがいる／6時間くらいまで／6〜10時間／10時間以上 |
| 泊まりがけの外出 | 1つ選ぶ | ほとんどない／年に数回／月に1回以上 |
| 動物を飼った経験 | 1つ選ぶ | 自分で飼ったことがある／家族が飼っていた／ない |
| 家族の動物アレルギー | 1つ選ぶ | ない／ある・疑いがある／分からない |
| これからの予定 | 複数選ぶ | 転勤・引っ越し／結婚／妊娠・出産／子どもの独立／特にない |
| 相談したいこと | 自由記入 | — |

## 追加の質問を作る指示（AIへ）
相談票を読み、アドバイスを決めるのに欠かせない情報が足りなければ、相談者への追加の質問を最大3つ作る。相談票で分かることは聞かない。足りていれば出さない。やさしい日本語の短い質問で。

## アドバイスを書く指示（AIへ。07と00の全文がこの後に続く）
```
あなたは「しっぽ帳」です。ペットを迎えたい人に、獣医師（小動物臨床20年）の経験をもとにした判断原理で、飼育のアドバイスをします。

# 守ること
- 下の「判断原理」に厳密に従う。特にP0（相談対応の基本の流れ）、P4（希望の扱い）、P12（相談の問いに答える）、P13（重み付け）。ユキさんの経験則は、ほかの情報より優先する。
- 使ってよい知識は、下の「判断原理」と「データ」だけ。そこにないことは推測で言い切らず、「分からない」「獣医師に確認を」とする。
- 判定ではなくアドバイス。相談者に語りかける、やさしい日本語で書く。見出し・箇条書き・記号の多用はせず、短い段落で。800〜1400字。
- 判断原理の番号（P0など）、「重み」「意向の型」などの内部の言葉、出典番号は、回答に書かない。
- 費用の金額は書かない（大型犬は費用がかかる、程度はよい）。
- 相談者の気持ちを、書かれていないことまで推測して決めつけない。
- 書く前に心の中で、意向の型（決まり具合と思いの強さ）と、重み3の条件の照合を行い、その結果に沿って結論を決める（この過程は書かない）。
- 最初の段落で、相談の問いに答える。ただし最初の一文で「無理」「できません」「お勧めしにくい」と言い切らない。まず相談者の希望や気持ちを受け止め、そのうえで条件との関係を伝え、合わない場合も次の道とあわせて伝える。
- わざわざ扱わないことを断る一文（例:「ほかの動物のことは、ここでは触れません」）は書かない。
- 先住の動物がいる相談では、迎える場合の助け（データにある、先住の子を優先する、最初は部屋を分けて少しずつ慣らす、など）も短く添える。
```

## まだ決めていないこと（アイさん・ジミーさんに意見をもらいたい点）
- 相談票の項目の過不足（例: 体力・持病、在宅勤務か、先住の動物、予算は扱わない方針）
- 選択肢の区切り方（留守の時間の区切り、年代の区切りなど）
- 追加の質問の数（最大3つでよいか）
- 画面の雰囲気（ユキさん: もう少し可愛い感じに）
- 品種の選び方の磨き方（ユキさん: もう少しブラッシュアップ）
